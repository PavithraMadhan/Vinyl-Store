# B2C E-Commerce Mockup Website

This is a **B2C e-commerce mockup website** currently under development. The project showcases a modern, responsive user interface for an online shopping experience.

## Status

The application is **in progress**, with features and functionality being actively developed.

## Demo

You can view the current UI live on Vercel:  
[Live Demo](https://vinyl-store-eta.vercel.app/)

## Features (Planned)

- Product listings with interactive hotspots
- Responsive design for mobile and desktop
- Shopping cart functionality
- User authentication and account management
- Checkout and payment integration

## Technologies Used

- Next.js
- React
- Material-UI (MUI)
- Vercel (for deployment)

---

> Note: This project is a mockup for UI/UX demonstration purposes and does not yet include full e-commerce functionality.
